# article-writing

Helps draft, structure, and critique articles in a consistent voice — built around the 300-word pitch format (title + hook + topics + why now) and long-form pieces.

## What you get

- **Skill: `article-writing`** — auto-activates when you're drafting, structuring, or revising articles. Provides voice and structure guardrails.
- **Command: `/write-article <topic>`** — start a structured draft from a topic.
- **Command: `/critique-article <path>`** — critique a draft on voice, non-AI feel, readability, structure, and conclusion strength.
- **Subagent: `article-critique`** — launch via the Agent tool for an independent second-pass critique that doesn't share your drafting context.

## Style assumptions

- 300-word pitch format: title + 1-line hook + 3 topic bullets + 1 "why now" line.
- Conversational, specific, non-AI tone. No "in conclusion", "moreover", "delve into".
- Concrete examples beat abstract claims.
- Title is provocative but accurate, not clickbait.
