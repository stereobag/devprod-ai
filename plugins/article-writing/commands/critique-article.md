# Critique Article

Draft path: $ARGUMENTS

Read the draft, then apply the `article-writing` skill critique dimensions:

1. Voice / non-AI feel
2. Hook strength
3. Specificity
4. Structure
5. Conclusion
6. Length / tightness

For each dimension:
- Score 1–5
- One-line rationale
- For any dimension scoring < 4: cite specific lines (with line numbers) and propose alternative wording

End with a "Top 3 edits" prioritized list — the changes that would move the most needle if the user only had time for three.

Do not rewrite the article wholesale. The user wants critique, not replacement prose.
