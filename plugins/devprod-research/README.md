# devprod-research

Daily research and digests on AI-augmented developer productivity — tools, trends, vendor moves, and notable incidents.

## What you get

- **Skill: `devprod-research`** — auto-activates when you're discussing developer productivity tools, AI coding assistants, IDE integrations, devprod metrics, or related topics. Gives Claude a research playbook so the answers stay grounded and current.
- **Command: `/devprod-daily`** — runs a structured daily research pass. Outputs a digest with: top 3 new tools/features, top 3 incidents or controversies, top 3 vendor moves, and one "what to watch" item.
- **Subagent: `devprod-researcher`** — launch with the Agent tool when you want deep, isolated research on a specific tool, vendor, or trend without polluting your main context.

## Suggested daily flow

```
/devprod-daily
```

Then iterate via the subagent for anything that needs depth.
